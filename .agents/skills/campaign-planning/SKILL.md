# Plan a campaign

Read [GOAL](../../../GOAL.md), [PROJECT](../../../PROJECT.md), [PLAN](../../../PLAN.md), [CAMPAIGN](../../../CAMPAIGN.md), [BOOKKEEPING](../../../BOOKKEEPING.md), [FINDINGS](../../../FINDINGS.md), and relevant existing evidence. Apply [AGENTS](../../../AGENTS.md) and [the campaign contract](../../../campaigns/TEMPLATE.md).

Find the decision this comparison can change. Check primary prior work and distinguish observed facts, proposed mechanisms, and novelty status. Present the resource budget before the design; compare adequately discriminating alternatives and plausible positive and negative outcomes. Do not invent numerical precision or compute forecasts without a stated basis.

Use the linked campaign templates. Create a new unused campaign for a new question; for an authorized revision, preserve the original and add a dated amendment. Keep one hypothesis and claim. Identify missing requirements with specific questions and allow a planning draft to remain incomplete.

Before calling a campaign ready, check frozen metrics/thresholds, controls, provenance/splits, independent units, replication, method correctness, resource cap, tracking, retention, and authorization. Resolve only decisions needed for the actual proposed run. Never interpret a completed planning document as execution permission.

Return the protocol/results links, readiness state, decision criteria, budget, and the next unresolved action. Keep the root index concise.
