# Plan a campaign

Read the current goal, settings, plan, campaign index, bookkeeping, findings, and relevant evidence. Follow [AGENTS](../../../AGENTS.md) and [the campaign contract](../../../campaigns/TEMPLATE.md).

- Identify one decision; check primary prior work and label novelty status.
- Budget before design. Compare adequately decisive scales and positive/negative outcomes; state the basis for forecasts.
- Use the contract's templates for a new question. Preserve originals when amending an existing campaign.
- Drafts may contain TODOs. Before declaring readiness, resolve the contract's scientific, correctness, tracking, retention, resource, and authorization requirements.

Return protocol/results links, criteria, budget, readiness, and the next missing decision. Planning does not authorize execution.
