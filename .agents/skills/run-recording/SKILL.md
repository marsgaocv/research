# Record an attempt

Read the frozen protocol, campaign RESULTS/RUN_LOG, relevant root [LOG](../../../LOG.md), and [recording rules](../../../AGENTS.md). Inspect actual artifacts before claiming success or spend.

- Preserve the attempt directory and console.txt. Record missing outputs and unknown times explicitly; no error file does not imply success.
- Append root LOG and campaign RUN_LOG entries with reciprocal evidence links. Append corrections; retain earlier records.
- Reconcile inclusive spend, estimates/revisions, variance, and totals without double-counting. Update RESULTS and CAMPAIGN; evaluate verdicts against frozen criteria.
- For interruptions, record last known state, partial outputs, unknowns, and permitted next action. Recording does not restart runs, signal processes, query devices, or upload data.

Return evidence links, accounting, unknowns, and next action. Execution completion and scientific success are separate.
